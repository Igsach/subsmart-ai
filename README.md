# 🚀 SubSmart AI - Intelligent Subscription Optimizer

SubSmart AI is a modern, AI-powered web application designed to help users track, manage, and optimize their recurring digital subscriptions (like Netflix, Spotify, AWS, etc.). Built specifically for the **AWS Builder Center Hackathon**.

## 🌟 The Problem
Normal users suffer from "subscription fatigue"—forgetting to cancel unused services or losing track of monthly vs. yearly billing cycles. This leads to hundreds of dollars wasted annually.

## 💡 The Solution
SubSmart AI provides a clean, visual dashboard to track all active plans in both **USD ($)** and **INR (₹)**. It features a real-time `Chart.js` expense breakdown and an AI recommendation engine that analyzes your billing cycles to suggest potential savings (e.g., switching from monthly to annual plans).

## 🛠️ Tech Stack
*   **Frontend:** HTML5, JavaScript (ES6)
*   **Styling:** Tailwind CSS (Modern, fully responsive UI)
*   **Data Visualization:** Chart.js
*   **Export Feature:** html2pdf.js (Export dashboard to PDF)
*   **Hosting:** AWS Amplify (CI/CD connected)

## ✨ Key Features
1. **Dynamic Currency Switcher:** Toggle between USD and INR in real-time.
2. **Auto-Icon Fetching:** Recognizes popular services (Spotify, Netflix, YouTube) and assigns correct icons.
3. **Interactive Charts:** Real-time expense breakdown chart.
4. **Export to PDF:** Download reports with a single click.
5. **AI Insights:** Automated suggestions for billing optimization.

## 🚀 How to Run Locally
Since this is a client-side application, simply clone the repository and open `index.html` in any modern web browser.
